# Ophthalmic Dispensing Software (ODS)

This repository contains the baseline product definition for an **Ophthalmic Dispensing Software (ODS)** platform.

## Core Functional Scope

ODS is intended to support optical practices and labs across the full eyewear lifecycle:

1. **Spectacle Frame Selection**
   - Frame recommendation based on facial features and style preferences.
   - Virtual try-on experience.
   - Frame catalog and inventory tracking.

2. **Ophthalmic Lens Selection**
   - Prescription-driven lens recommendations.
   - Consideration of lens material, coatings, and lifestyle needs.
   - Decision support for opticians and eye care professionals.

3. **Facial Measurement**
   - Capture and management of key measurements: pupillary distance (PD), segment height, and fitting parameters.
   - Support precise fit and optical comfort.

4. **Lens Surfacing and Design**
   - Calculations for lens curvature and thickness.
   - Manufacturing-oriented design handoff based on prescription data.

5. **Lens Ordering**
   - Structured order entry for custom lenses.
   - Electronic transmission of orders to manufacturing partners.

6. **Optical Products Marketing**
   - Customer communication and campaign management.
   - Promotion planning and online visibility workflows.
